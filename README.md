# minikit-room

## Run locally

### Frontend

Run

```bash
yarn run dev:frontend
```

### Create Google application for authentication

- Navigate to https://console.developers.google.com/.

- Create a Google Cloud Project.

- Enable the Google Drive API.

- Create OAuth 2.0 credentials (Web application type).

- Add http://localhost:4200 as an authorized JavaScript origin in Google Cloud Console.

- You’ll get a Client ID for the app.
